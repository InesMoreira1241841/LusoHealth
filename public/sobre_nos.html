Sobre o Projeto

O LusoHealth é um sistema web desenvolvido no âmbito da unidade curricular de Sistemas de Informação e Bases de Dados Aplicados à Saúde (SIBDAS), integrada no curso de Licenciatura em Engenharia Biomédica do Instituto Superior de Engenharia do Porto (ISEP).

Este projeto tem como objetivo principal o desenvolvimento de uma plataforma inteligente para o inventário clínico hospitalar, otimizando a rastreabilidade, gestão de fornecedores e controlo de criticidade de equipamentos médicos essenciais ao ecossistema de saúde.
